# My Start Page

一个极简、美观、可自定义的浏览器起始页。支持多搜索引擎、快捷导航、便笺、工具箱与本地天气。基于原生 HTML / CSS / JavaScript，无构建步骤，开箱即用。

## ✨ 功能特性

- **多搜索引擎**：内置 Google、Bing、百度、DuckDuckGo、Yahoo、Yandex、GitHub、知乎、AOL、Naver、Ecosia、Brave、Ask.com 等，图标采用官方品牌配色。
- **快捷导航**：右击空白处或点击「九宫格」按钮打开导航面板，可添加 / 编辑 / 删除自定义站点。
- **便笺**：点击「便笺」按钮滑出侧边栏，随手记录。
- **工具箱**：单位换算、二维码生成、世界时钟。
- **本地天气**：基于 IP 定位显示天气（可关闭）。
- **主题与背景**：亮色 / 深色主题，自定义壁纸或每日壁纸。
- **关于**：点击顶栏「关于」按钮查看项目信息。

## 🚀 使用

直接用浏览器打开 `index.html` 即可。

或通过本地静态服务器（推荐，避免某些 API 的本地文件限制）：

```bash
# Python
python3 -m http.server 8080

# 然后访问 http://localhost:8080
```

## ⌨️ 交互说明

| 操作 | 效果 |
| --- | --- |
| 在搜索框输入并回车 | 使用当前选中的搜索引擎搜索 |
| 点击搜索框左侧图标 | 切换搜索引擎 |
| 右键页面空白处 | 打开快捷菜单（导航 / 便笺 / 设置） |
| 顶栏图标按钮 | 设置、便笺、关于 |

## 🔧 自定义

- **添加快捷方式**：打开导航面板 → 点击「+」→ 填写名称 / 网址 / 图标 slug（Simple Icons 名称）。
- **搜索引擎图标**：位于 `logos/` 目录，为 SVG 格式，可直接替换。
- **数据持久化**：所有配置保存在浏览器 `localStorage`（键名 `startpage_state`），可在设置中导出 / 导入 / 清空。
